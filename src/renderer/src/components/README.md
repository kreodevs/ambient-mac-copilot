# Components

## Shell y navegación

| Componente | Descripción |
| --- | --- |
| `CommandPalette` | Paleta ⌘K — navegación, ajustes, nuevo hilo, pin |
| `WindowPinButton` | Anclar ventana en la barra superior |
| `SegmentedControl` (kreo) | Chat / Ajustes en toolbar |

## Paneles

| Componente | Descripción |
| --- | --- |
| `ChatPanel` | Hilos + historial + compose |
| `SettingsPanel` | Ajustes con sidebar (sección controlable desde App) |
| `OnboardingWizard` | Setup inicial (omitible) |
| `DiagnosticsPanel` | Diagnóstico de permisos y prereqs (Fase 0) |
| `ToolPreviewCard` | Confirmación de acciones sensibles |
| `EmailListCard` / `EmailDetailCard` | Resultados de correo (Fase 1) |
| `UpdateBanner` / `UpdatePanel` | Actualizaciones automáticas desde GitHub Releases |
